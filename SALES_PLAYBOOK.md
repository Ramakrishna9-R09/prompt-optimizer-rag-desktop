# Prompt Optimizer Sales Playbook

## Ideal first customer

Windows-based software agencies with 5–50 developers, multiple client repositories, and regular use of ChatGPT, Claude, Codex, Cursor, or browser AI tools.

## Positioning

Prompt Optimizer is the privacy-first desktop context layer that gives AI assistants the correct workspace context without silently mixing information between clients.

## Paid pilot

- 30 days, up to five developers
- Installation and workspace setup
- One onboarding session
- Weekly usage review using local counters
- Direct support and final value report
- Suggested price: INR 15,000–30,000 plus applicable taxes

## Qualification questions

1. How many developers use AI assistants each week?
2. How often do they repeat repository or client context?
3. Do developers work across multiple client repositories?
4. What information is prohibited from entering external AI systems?
5. Which AI providers and IDEs are approved?
6. What outcome would justify paying for this product?

## Ten-minute demo

1. Show the always-on status and global shortcuts.
2. Optimize a vague prompt with `Ctrl+Shift+Space`.
3. Switch projects and run workspace-scoped RAG with `Ctrl+Alt+Space`.
4. Show that unrelated memory is excluded.
5. Demonstrate secret redaction and injection warnings.
6. Open local value metrics and propose a pilot baseline.

## Outreach message

> I built a Windows context layer that gives AI assistants the correct project context with one shortcut while isolating data between client workspaces. I am selecting five software teams for a paid 30-day pilot. Could I show you a ten-minute demonstration?

## Pilot success metrics

- Weekly active developers
- Optimizations per active developer
- Autopilot suggestion acceptance rate
- Context-mode adoption
- Estimated time saved
- Verified insertion success
- Secrets or unsafe context blocked
- Pilot-to-paid conversion

## Objections

**"ChatGPT already improves prompts."**  
The product's value is workspace-scoped context, cross-application operation, local memory, verified insertion, and policy controls—not rewriting alone.

**"We cannot send source code externally."**  
Use bounded project context, secret redaction, workspace isolation, and an approved provider. A local-model provider should be added for teams that prohibit external inference.

**"Why pay for open-source software?"**  
Charge for signed installers, managed updates, onboarding, support, policy configuration, team administration, and enterprise assurance. Consider a future dual-license strategy only with legal advice and clean ownership of all contributions.

## Never claim

- SOC 2, ISO 27001, GDPR compliance, or HIPAA compliance without evidence
- Guaranteed prevention of all leaks or prompt injection
- Revenue projections as booked revenue
- Customer logos or testimonials without written permission
